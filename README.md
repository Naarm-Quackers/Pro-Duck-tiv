# Welcome
## Set Up Instructions:
To check that you are running the correct version of node
in Terminal run:
- node -v Should print "v24.15.0".
- npm -v Should print "11.12.1".

To clone the Project in desired folder run these commands in the terminal:
- git clone https://github.com/Naarm-Quackers/Pro-Duck-tiv.git
- cd Pro-Duck-tiv

If it ask for *Username* please enter your github **username** and for the *Password* enter your **personal access token** for the repo.

## How to set up Personal Access Tokens for Origination
If you don’t have a personal access token for this organisations repo one can be created by:
- Clicking on the user profile icon in top right corner of github.com
- Click on Settings -> Developer Settings
- Click on Personal access tokens -> Fine-Grained tokens 
- Then Click Generate New Token 
- Make sure that instead of selecting your user name, you select the organisations name **Naarm-Quackers**
- Select the Pro-Duck-tiv repo
- Then add Read and Write Repository permissions for actions, code, issues, pull requests, and workflows (meta data will be added automatically)
